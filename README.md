# VitpPrep – Your All-in-One Interview Prep Buddy 🚀

Hey everyone! 👋

I’m excited to share **VitpPrep**, a project I worked on for three months while learning and exploring full-stack development.

The idea behind VitpPrep was simple: create one place where students and freshers can prepare for technical interviews without jumping between different platforms. Whether you're preparing for product-based companies or revising your computer science fundamentals, VitpPrep brings several useful resources together.

## What can you find in VitpPrep?

- **DSA Practice:** Topic-wise questions to help you practice Data Structures and Algorithms.
- **Aptitude:** Questions on quantitative aptitude, mathematics, and logical reasoning.
- **Core CS Subjects:** Notes and theory sections for OS, DBMS, and OOPs.
- **Admin Panel:** Manage questions with role-based access.
- **Dark Mode:** A darker theme for a more comfortable experience.
- **Smooth UI:** A clean, responsive design with animations that work across different screen sizes.

## Tech Stack

**Frontend:** React.js, Tailwind CSS, shadcn/ui, Framer Motion, Redux Toolkit

**Backend:** Node.js, Express.js, MongoDB

**Authentication & Security:** JWT, bcrypt, cookie-based authentication, Helmet, and role-based access control.
